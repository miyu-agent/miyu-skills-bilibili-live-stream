# Bilibili live streaming

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a skill package for Miyu. It provides one tool, `bilibili_live`, and one skill, `bilibili-live`, which control your own Bilibili live room: check its status, look up categories, change the title and category, start a stream and get the stream key, end the stream, and log in by scanning a QR code.

The package contains these files:

| File | Description |
|---|---|
| `scripts/bilibili_live.py` | The tool itself. The `command` parameter takes `status`, `areas`, `update`, `start`, `stop`, `login` or `logout`; the other parameters are `title`, `area`, `search`, `parent`, `refresh`, `wait` and `format` (`md`/`json`). |
| `skills/bilibili-live/SKILL.md` | The skill's instructions: three hard rules (get consent before going live; while you are live, viewers see settings changes immediately; when a category is ambiguous, let the user choose), the login flow and the command table. |

**Logging in**: logging in takes two steps. The first `login` call writes a QR code to `bilibili-login-qr.png` in the workspace and returns, and the AI shows it to you with `show`; after you scan it, tell the AI, and the AI calls `login` once more to finish. You can also pass `wait` (at most 100 seconds) to wait for the scan within a single call.

**The login state** is stored in the state folder Miyu gives the script, `MIYU_STATE_DIR` (in `credentials.json`, with permissions 0600). It is kept separately for each Miyu account and survives restarts: each account scans its own code and runs its own live room. The category list is a cache, kept in `MIYU_CACHE_DIR`.

**Where it can be used** (`Venues: local, private`): sessions on this computer and private chats on chat platforms can use it; group chats cannot. Because anyone can talk in a private chat, the commands that change the live room or switch the login (`update`, `start`, `stop`, `login`, `logout`) are only for the owner of the machine (`MIYU_CALLER_OWNER=1`), and everyone else can only use `status` and `areas`. Private chats with strangers belong to the system account, so they cannot see your login.

**`Clicall: no`**: starting a stream, ending it and changing the title all have effects other people can see, so the tool can only be called directly; the AI cannot call it through `miyu call` in a command.

The tool uses only the Python standard library (it encodes the QR code PNG itself). The API and signing come from [bili-live-hime](https://github.com/Rsplwe/bili-live-hime).
